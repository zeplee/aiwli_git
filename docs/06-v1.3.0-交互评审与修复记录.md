# v1.3.0 改版与修复记录

> 2026-10-01 · 基于 v1.2.0（`52efe09`）→ `f273153` · analyze 全绿 · 真机验证通过（绑定弹窗待点验）

## 一、交互评审结论（对照手机上的参考应用）

参考对象：一个成熟的 Flutter git 客户端、MGit、系统文件管理器（可展开列表 + 底栏 3~5 tab 模式）。

| 评审项 | 结论 |
|---|---|
| 底部 3 tab 结构 | 合理，与文件管理器一致，保留 |
| 仓库卡片可展开 | 合理（文件管理器风格），保留并增强 |
| 工作台顶部 5 子页 | **改为 3 子页**（改动·历史·分支）——暂存/远程是低频操作，收进同步菜单推入二级页 |
| 拉取/推送无远程只报错 | **改为弹窗引导绑定**（IDEA 的思路：缺什么引导补什么） |
| 多远程 | 引擎本来就支持（remoteAdd 任意名），UI 收口：推送目标 = 分支上游 > 唯一远程 > 选择器 |
| ↑n 待推送角标 | **新增**（IDEA VCS widget 同款：底栏工作台 tab 显示 ↑n） |
| Material 3 | 已是 M3；本轮补 **SliverAppBar.large 大标题** + **Material You 动态取色** + 触感反馈 |

## 二、本轮改动明细

### 交互增强
- **绑定引导弹窗**（`widgets/remote_dialogs.dart`）：拉取/推送/获取缺少远程时不再只报错——弹窗输入远程名+URL 绑定后原操作自动继续；拉取还缺上游时自动设置跟踪（`origin/分支名`）。
- **多远程上游管理**：分支菜单新增「设置上游跟踪」；新增引擎操作 `branchSetUpstream`（Rust `ops_branch.rs` + dispatch + FFI）。
- **IDEA 式 ↑n 角标**：底栏「工作台」tab 显示当前仓库待推送提交数（`Badge`）；同步信息由仓库卡片预取与工作台快照双路径回报，AppShell 按当前仓库过滤。
- **收起态卡片完整元数据**：预取从 `openRepo`（只有分支名）升级为 `getSnapshot(commitLimit:1)`（分支+↑↓+最近提交）——收起态即显示 ↑n↓n，展开即查即得；拉取/推送完成后单卡刷新。
- **搜索防抖**：历史页输入即搜（500ms 防抖），不用再点箭头。
- **触感反馈**：提交/拉取/推送/克隆成功时 `HapticFeedback`。
- **M3 大标题**：仓库页改 `SliverAppBar.large`（滚动收缩），refresh 指示器与 Sliver 结构适配。

### 隐藏 bug 修复（最重要）
- **B1（P0 数据丢失）「检出此提交」实际执行 `reset --hard`**：`CommitDetailPage` 的检出菜单实现成了 `engine.reset(mode:'hard')`——移动分支指针并丢弃后续提交，与文案"分离 HEAD 检出"完全不符。修复：新增 Rust `checkout_commit`（`set_head_detached` + force checkout），不动分支指针；检出成功后自动返回列表。
- **B2（P1）工作台同步菜单在 embedded 模式不可达**：同步菜单只存在于 `WorkbenchPage` 的非嵌入 AppBar（死代码），工作台 tab 里拉取/推送无从触发。修复：同步流抽为 `pages/sync_flow.dart`，菜单移到宿主 AppBar；`WorkbenchPage` 变纯子页（删 `embedded` 参数与死代码 Scaffold）。
- **B3（P1）MCP `git_fetch`/`git_pull` 不带凭据**：私有仓库经 MCP 拉取/获取必然认证失败。修复：两处补 `cred: await _cred()`。
- **B4（P1）mutation 风暴**：任何操作 → `ValueKey` 变化 → 5 个子页全部销毁重建（闪烁 + 全量重载）。修复：key 稳定（仅仓库名参与），子页通过 `tick` 参数在 `didUpdateWidget` 里自刷新。
- **B5（P2）`bindRemoteDialog` 读已 dispose 的 controller**：弹窗文本在 `finally dispose` 之后读取，必然抛异常。修复：dispose 前捕获。
- **B6（P2）强制推送确认文案格式怪**：`覆盖远程 origin_main` → 改为 `覆盖远程 origin 的 main`。
- **B7（P2）版本三处不一致**：MCP serverInfo 硬编码 `1.1.0`、settings 硬编码 `1.2.0`。修复：新增 `core/version.dart` 单一常量，两处引用。
- **B8（P3）build 后残留注释**、`friendlyError` 指引过时（"设置"→ 实际在「远程与仓库设置」）。

### MCP 完善（30 → 38 个工具）
- **修复**：`git_fetch`/`git_pull` 带凭据（B3）。
- **新增**：`git_tag_create` / `git_tag_delete` / `git_cherry_pick` / `git_remote_add` / `git_remote_set_url` / `git_remote_delete` / `git_branch_set_upstream` / `git_ignore_get` / `git_ignore_set` —— 引擎能力全部对 AI 侧开放。
- `toolByName` 改 map 索引（O(1)）；`serverInfo.version` 接版本常量。

### 代码结构（整洁与规范）
- `pages/`：10 个文件 = 页面 + `sync_flow`（同步流）+ `commit_detail`（从 widgets/ 归位）。
- 删除死代码：`lib/ui/main_shell.dart`（旧 5-tab 壳）、空 `lib/src/`、workbench_page 的非嵌入分支与 `_sync`/`_cred`（已迁移）。
- `widgets/`：dialogs / diff_view / remote_dialogs（远程交互收口）。
- `engine/ffi.dart`：新增 `checkoutCommit`/`branchSetUpstream` helper；`HistoryPage.refreshTick`（从未使用的回调参数）删除。
- analyze：0 error / 0 warning（async-gap 的 `mounted` 检查全部补齐）。

### UI 潮流
- Material 3 已启用（`useMaterial3: true` + `NavigationBar`）；本轮补齐当前主流三件套：
  - **Material You 动态取色**（`dynamic_color` 包）：Android 12+ 按壁纸生成 ColorScheme，非 Android / 不支持时回退石墨+蓝静态色板；
  - **M3 大标题**（`SliverAppBar.large`）；
  - Badge / 触感反馈。
- Flutter 3.47.1 stable 编译。
