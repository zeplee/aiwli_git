# 09 · v1.4.2 交互扁平化：左滑侧栏 + 弹层化二级页

日期：2026-10-02

## 背景

v1.4.1 收尾时用户反馈两点：

1. **工作台左上角不好点**——希望从工作区左滑直接拉出侧边栏；
2. **层级还想再浅**——能不做成二级页面的就去掉。

## 根因

- 抽屉（Drawer）在 v1.4.1 就已存在，但 Scaffold 默认 `drawerEdgeDragWidth`
  只有 20dp，且内容层 TabBarView 会参与水平手势竞争——实际几乎滑不出来，
  用户只能去点左上角菜单按钮。
- 「切换仓库」按钮挂在 AppBar 右上角，与抽屉功能完全重复（抽屉直切更快）。

## 改动

| 项 | 之前 | 之后 |
|---|---|---|
| 拉出侧栏 | 左上角按钮（默认 20dp 边缘手势形同虚设） | 左缘 120dp 内左滑即拉出；按钮保留兜底 |
| Stash 管理 | 推入二级页 StashPage | 满高底部弹层 StashSheet（下拉即关） |
| 远程与仓库设置 | 推入二级页 RemotesPage | 满高底部弹层 RemotesSheet |
| 侧栏「管理分支…」 | 推入 BranchesPage（与「分支」tab 完全重复） | 直接切到工作台「分支」tab |
| AppBar 右上角「切换仓库」 | 按钮（与抽屉重复） | 删除；侧栏底部新增「仓库主页」「应用设置」一步直达 |

保留下来的二级页（刻意不扁平化）：

- 历史 → 提交详情：标准列表→详情模式，内容承载量大；
- 设置页：935 行多分组内容，塞弹层/侧栏都会破坏可读性。

弹层统一走 `widgets/dialogs.dart` 的 `showFullSheet`（isScrollControlled +
useSafeArea + 93% 屏高），`full_sheet_test.dart` 锁定行为契约（满高、内容
可见、下拉可关）。

## 教训

- Drawer 存在 ≠ Drawer 可用：默认边缘手势区太窄 + 内容层手势竞争时，
  必须显式调大 `drawerEdgeDragWidth` 并真机验证手势。
- 验收导航改动要连「手势路径」一起验，不能只点按钮。

## 验证

- `flutter analyze` 0 issues；测试 33 个全过（新增满高弹层契约）。
- release 构建 v1.4.2+8，签名与正式证书一致，覆盖安装数据保留。
- 真机：左缘滑动拉出抽屉、抽屉直切仓库、Stash/远程弹层、管理分支直切
  分支 tab、抽屉底部进设置/仓库主页。
