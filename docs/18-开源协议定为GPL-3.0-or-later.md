# 18 · 开源协议定为 GPL-3.0-or-later（由 MPL-2.0 变更）

日期：2026-10-12　范围：仅许可证与相关文案，无代码改动

## 一、结论

- 自本版本起以 **GPL-3.0-or-later** 分发，`LICENSE` = GPLv3 官方全文（gnu.org `gpl-3.0.txt`，
  674 行，sha256 `3972dc9744f6499f…`）。
- 此前版本（≤ 1.5.24）为 **MPL-2.0**：该许可对已接收者继续有效、不可撤回，本次变更不
  影响他们对手中旧版本的权利。

## 二、为什么从 MPL-2.0 换成 GPL-3.0-or-later

MPL 是**文件级** copyleft：改动过的 MPL 文件要开源，但**新增文件可以闭源**。后果是别人可以在
引擎旁边加一层闭源 UI、打包直接卖钱，而改动拿不回来。GPL 是**整包** copyleft，正是「下游
也得开源」的落点。

| 维度 | MPL-2.0 | GPL-3.0-or-later |
| --- | --- | --- |
| 下游修改是否必须开源 | 仅 MPL 文件；新增文件可闭源 | 派生作品整包必须同样开源 |
| 闭源商用（含打包嵌入） | 允许 | 必须开源，或另行取得商业授权 |
| 私有使用 / 内部修改 | 无义务 | 无义务（copyleft 只在分发时触发） |
| 品牌（名称 / 图标） | 不在授权范围 | 不在授权范围（见 README） |
| 自编译版上架 App Store | 可行 | 冲突 → **iOS 暂不提供社区版** |

## 三、吸收上游代码的口径

| 上游许可 | 能否直接吸收 | 说明 |
| --- | --- | --- |
| MIT / BSD / ISC | ✅ | 保留版权与许可声明 |
| Apache-2.0 | ✅ | 与 GPLv3 兼容（与 GPLv2 不兼容） |
| MPL-2.0 | ✅ | MPL §3.3 二级许可 |
| GPLv3 / AGPLv3 | ✅ | 同族；AGPL 部分须整体按 AGPL 遵守 |
| GPLv2-**only**（如 git 本体） | ❌ | 不可吸收；只能作为互操作对象（调 CLI） |
| 专有代码 | ❌ | 不可吸收 |

**本仓库依赖核对**：Flutter / Dart（BSD-3）、Material Icons（Apache-2.0）、各 Dart 包（MIT / BSD）、
git2-rs / serde 等（MIT OR Apache-2.0）、OpenSSL（Apache-2.0）、cargokit（MIT）、libgit2
（GPLv2 + linking exception，**靠 linking 许可使用，不依赖其 GPLv2 选项**）——全部与
GPL-3.0-or-later 相容，整包可按 GPL-3.0-or-later 分发。详见 `THIRD-PARTY-NOTICES.md`。

## 五、GPL-3.0-or-later 的持续性义务（发布检查单）

1. **每个二进制都要能给对应源码**（§6）：release 附源码包或指向同 tag 的完整源码
   （含 `rust/`、`rust_builder/`、构建脚本与配方）。
2. **不得增加额外限制**（§10）：许可证文本内不得附加禁止商用等条款；品牌限制放在
   README / CONTRIBUTING（不在许可证内）即可。
3. **不得用安装信息限制修改版**（§6 Installation Information）：不得做「签名一改就拒绝
   运行」这类机制。
4. **保留声明**：再分发须保留 `LICENSE`、`THIRD-PARTY-NOTICES.md` 与本文件。
