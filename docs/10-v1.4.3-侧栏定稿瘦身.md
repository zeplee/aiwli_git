**头部也不放仓库信息，快捷拉推行一并撤除**。

## 改动

### 新增 `lib/pages/repo_drawer.dart`（公共 `RepoSidebar`）

侧栏只做三件事：

1. **仓库目录**：最近使用（真实 recents ∩ 列表，≤5）+ 全部仓库两组，
   点仓库直接切换，当前仓库高亮（folder_special + check_circle）；
2. **＋ 添加仓库**：底部弹层二选一——扫描本地（Isolate 跑 RepoScanner，
   写回 scanCache 并就地刷新列表）/ 云端导入（复用 CloudImportSheet，
   导入成功直接 onOpenRepo 打开）；
3. **底部固定全局入口**：仓库主页 / 应用设置。

头部仅应用名「AiwliGit · 仓库目录」，无仓库信息、无快捷同步按钮。

### `workbench_host.dart` 收缩

- 删除内嵌 `_RepoSidebar`（分支/远程分支/标签/Stash/远程树、快捷拉推、
  `_openBranchTab` 全部移除，约 490 行 → 新组件约 240 行）；
- `engine` / `prefs` 导入随之移除（宿主不再直接读引擎）；
- 抽屉模式的 pop 职责收拢到宿主包装回调（onGoRepos/onOpenSettings）。

### 仓库专属操作的去处（全部已有，无一丢失）

| 侧栏移除项 | 现有入口 |
|---|---|
| 分支/远程分支/标签/管理分支 | 工作台「分支」tab |
| Stash 入口 | 「更多」菜单 → 临时保存（修改/管理）→ StashSheet |
| 远程列表/绑定 | 「更多」菜单 → 远程设置 → RemotesSheet |
| 快捷拉取/推送/获取 | 工作区同步按钮 + 「更多」菜单 |
