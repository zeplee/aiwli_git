# v1.4.4 — 侧栏目录化终稿与仓库主页页删除

日期：2026-10-02　版本：1.4.4+10

## 定稿追加（10-02 用户反馈逐条）

v1.4.3 完成了"侧栏只做仓库目录"的第一刀，但留了三处尾巴，本轮全部清掉：

1. **「仓库主页」按钮与页面整体删除**。仓库主页页（ReposPage，874 行）
   的信息（仓库卡片、同步角标、扫描入口）侧栏目录全部可替代，属重复入口。
   删除后牵连的导航收敛：
   - AppShell 的 IndexedStack（仓库页/工作台两页常驻）拆掉，工作台即唯一主页；
   - WorkbenchHost 的 `goRepos` 参数链路（侧栏按钮、空态「去仓库页」）全删；
   - **新用户起点**：无仓库时落在工作台空态，空态自带
     「扫描本地仓库 / 云端导入」两条动线（扫描发现仓库直接打开第一个），
     不再依赖独立仓库页。

2. **「最近使用」分组删除**。目录应当稳定，不该自己变。侧栏改为
   全部仓库**平铺一列**；recents 数据仍保留（冷启动恢复上次仓库、
   MCP `git_recents` 工具仍依赖它），只是不再作为侧栏分组展示。

3. **长按拖动手动排序**。`ReorderableListView` + 新增
   `Prefs.repoOrder / setRepoOrder` 持久化。排序规则抽成纯函数
   `orderedRepos(candidates, order)`：手排且仍存在的仓库按用户顺序排前，
   新发现/云端导入的按发现顺序接尾，stale 排序条目自然丢弃。

4. **「自动检测」按钮**（头部 radar 图标）：免弹层一键重扫
   Projects / Documents / Download 标准目录，静默补进新仓库，
   SnackBar 汇报「新增 N 个（共 M）」。与「＋添加仓库」弹层里的
   「扫描本地仓库」同一实现（抽出 `scanLocalRepos()` 共用）。

5. **侧栏顶部与系统状态栏重叠修复**。Drawer 自身不处理 insets，
   侧栏内容（SafeArea）包住 Column，顶部避让状态栏、底部避让手势条；
   宽屏常驻侧栏在 AppBar 之下，SafeArea 自动 no-op，无副作用。

## 交互遗留盘点（本轮自查）

- 「＋添加仓库」从列表内滚动区**提为底部固定**（与「应用设置」并列），
  空目录时也始终可见、无需滚动；
- 头部显示 `仓库目录 · N` 计数，自动检测进行中有转圈反馈；
- 拖动排序即时落盘（`onReorderItem`，Flutter 3.41 新 API，自带
  newIndex 移位校正，弃用 `onReorder`）。
