## 二、新架构

```
lib/
├── main.dart              # AiwliGitApp：boot 序列（setDir→themeMode→恢复lastRepo）
├── ui/
│   ├── theme.dart         # 新：深浅两套主题（石墨+蓝）
│   └── app_shell.dart     # 重写：底部 3 tab（仓库/工作台/设置）
├── core/
│   ├── scan.dart          # 新：RepoScanner 递归扫描 + relTime
│   └── prefs.dart         # 改：files 目录落点 + scanCache + themeMode
└── pages/
    ├── repos_page.dart    # 新：工程目录页（扫描+可展开卡片+空状态）
    ├── workbench_host.dart# 新：工作台 tab 宿主（顶部 5 子页导航）
    ├── settings_page.dart # 新：设置页（MCP/凭据/外观/关于）
    └── workbench_page.dart# 改：embedded 参数（嵌套时无 AppBar）
```

**导航层级**：仓库列表（tab 1）→ 点`打开`→ 自动切工作台（tab 2）→ 顶部子页（改动·历史·分支·暂存·远程）。设置（tab 3）独立。

**工作台 tab**：无仓库时显示引导（`去仓库页`按钮）；有仓库时 AppBar 显示仓库名+`切换仓库`，顶部 5 子页 TabBar，TabBarView 承载原有 5 页面。

## 三、真机测试中发现并修复的 Bug

### B1（高危）改动子页整页空白 —— TabBarView 没接 controller

**现象**：打开仓库后"改动"子页只有 AppBar+TabBar，y=376 以下**完全空白**（uiautomator 仅 10 节点，OCR 确认无内容）。

**根因**：`workbench_host.dart` 的 `body: TabBarView(children: [...])` **没传 controller**——AppBar 上的 TabBar 用的是 `_tabs`，TabBarView 内部解析 `DefaultTabController.of(context)` 拿到 null，子页永不构建。

**修复**：`body: TabBarView(controller: _tabs, children: [...])`。修复后 OCR 复验：状态卡+变更/差异子tab+提交栏全部渲染。

### B2（高危）prefs 全部静默丢失 —— 落点在系统可清理目录 + 目录不存在

**现象**：code_cache 被系统清理后 prefs 全丢（MCP 开关/凭据/最近仓库）。且 `Directory.systemTemp` 指向的 cache 目录在全新安装时**不存在**，`File.writeAsString` 不建父目录 → 读写**全部静默失败**（catch 吞掉）——表现为 MCP 永远起不来、引导卡片反复出现。

**修复**：
1. MainActivity.kt 新增 `appFilesDir` MethodChannel，Dart 启动时查询 `filesDir.absolutePath`（files 目录系统永不清理）
2. `Prefs.setDir()` 注入落点，`_save()` 前 `f.parent.create(recursive: true)` 兜底
3. 查询失败回退 systemTemp+create

**验证**：seed prefs 到 files → force-stop+重启 → MCP 自动启动（ping 200）✓

### B3（中）凭据对话框类型混乱 —— 运行时必崩

`showDialog<bool>` 却 `Navigator.pop(ctx, 'clear')`（String）→ 类型错误。改 `showDialog<String>`，'clear'/'save'/'cancel' 三态处理。

### B4（低）工作台双 AppBar 堆叠

WorkbenchPage 嵌入 TabBarView 后与 WorkbenchHost 的 AppBar 叠加。加 `embedded` 参数：嵌入时隐藏自身 AppBar，子 tab（变更/差异）保留在顶部。

### B5（低）RemotesPage 的 NavigationDestination label 错写成"设置"

v1.1.0 的 main_shell.dart 里第五个 tab 标签是"设置"但页面是远程仓库页。改版后随 MainShell 废弃，新 WorkbenchHost 中正确标为"远程"。

## 五、已知问题与后续

- **uiautomator 对本 Flutter 版本的 Switch/Text 呈现不全**（text 全空、Switch 无独立节点）——自动化测 UI 靠 content-desc+OCR，人工点验不受影响
- **仓库页 uiautomator "could not get idle state"**：改动子页偶发持续忙碌（动画循环），不影响人工使用，待查
- prefs 的 lastRepo 写入在 setDir 注入前发生的一次时序竞态已通过 boot 顺序消除，长期观察
- 主题只做了深/浅两套固定色，未做动态取色（Material You）
