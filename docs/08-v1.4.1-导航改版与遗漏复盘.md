# 08 · v1.4.1 导航改版：移除底部 tab（遗漏复盘）

## 背景

v1.4.0 交付了"工作台仓库侧边栏（手机抽屉 / 宽屏双栏）+ Diff 左右分栏"等一揽子改动，
但对话中明确说过**底部三 tab（仓库/工作台/设置）随侧边栏改版不再需要**——交付时漏删。
本轮用户复核发现，顺带全面复盘承诺清单。

## 遗漏清单与修复

### 🔴 底部 tab 未删（本次主修）

- `app_shell.dart` 仍保留 `bottomNavigationBar: NavigationBar`（窄屏）与
  `NavigationRail`（宽屏 ≥700dp），三页 IndexedStack（仓库/工作台/设置）模型。
- **修复**：重写 AppShell → 两页 IndexedStack（仓库页 / 工作台）：
  - 仓库页即主页；打开仓库即进工作台；恢复 lastRepo 时仍直入工作台；
  - 「切换仓库」按钮窄屏/宽屏都显示（原来 `if (!wide)` 只在窄屏，宽屏删 rail 后会无路可回，连带修复）；
  - IndexedStack 保持两页常驻，来回切换不丢扫描结果与工作区状态；
  - ↑n 角标随 tab 移除：仓库卡片自带 ↑n↓n（后台预取），侧栏分支行也有，shell 级角标本就冗余。

### 🟠 删 tab 后的入口补位

- **设置**：仓库页 AppBar 加齿轮（`onOpenSettings`），工作台「更多」菜单加「设置」项；
  回调由 AppShell 统一提供，保证 `onThemeChanged` 所有权单一。
- **宽屏切仓库**：工作台「切换仓库」按钮去掉窄屏限制。

### 🟡 连带清理

- `theme.dart`：`navigationBarTheme` 成死代码，删除（25 行）。
- README：补导航描述；"Dart 单测 29 个"更新为 32 个（之前 v1.4.0 加了 2 个也漏更新）。
- pubspec：1.4.1+7（同签名可覆盖安装，数据保留）。
